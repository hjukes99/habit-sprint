# Habit Sprint

A tiny local-first habit tracker for daily consistency.

## Features
- Define up to 3 daily habits
- Mark today’s completion per habit
- View today’s status and streaks
- Local JSON persistence

## Stack
- Node.js 20+
- TypeScript

## Setup
```bash
npm install
```

## Run
```bash
npm run build
npm start
```

## Test
```bash
npm test
```

## Docker
```bash
docker build -t habit-sprint .
docker run --rm habit-sprint
```
