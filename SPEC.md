# SPEC — Habit Sprint

## App
Habit Sprint is a tiny CLI app that helps a solo user run short, repeatable habit sessions with a countdown and completion streak tracking.

## Target user
- Busy builders/operators who want a minimal way to enforce one focused habit block at a time.
- Command-line comfortable users who value speed over UI complexity.

## MVP
1. Start a sprint with a named habit and duration (minutes).
2. Show a live countdown in terminal.
3. Mark sprint complete and persist completion in local JSON file.
4. Show current streak and total completions.
5. Include a smoke test proving the app boots and basic streak calc works.
