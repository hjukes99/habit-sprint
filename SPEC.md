# Habit Sprint — MVP Spec

## App Summary
Habit Sprint is a minimal daily habit tracker for people who want to commit to 1–3 key actions each day and see quick streak feedback.

## Target User
- Solo builders and busy operators who want a lightweight accountability loop.
- Users who dislike heavy productivity apps and want a fast CLI/web-lite tracker.

## MVP Scope
- Create habits with a short name.
- Check off habit completion for "today".
- List today’s habits and completion status.
- Show current streak per habit.
- Persist data locally in JSON for simplicity.

## Non-Goals (MVP)
- User accounts/auth
- Cloud sync
- Mobile app
- Complex analytics dashboards

## Success Criteria (First 48h)
- App runs locally with one command.
- Basic smoke test passes.
- Core commands (add/list/check/streak) work on local data.
