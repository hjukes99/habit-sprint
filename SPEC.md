# Habit Sprint — MVP Spec

## App summary
Habit Sprint is a tiny daily habit tracker that helps a user set up to 3 habits and mark each one done once per day.

## Target user
Solo builders and busy operators who want a frictionless daily consistency tracker without account setup.

## MVP scope
- Add up to 3 habit names in a local JSON file.
- Mark habit completion for today.
- Show a simple text dashboard of today’s status and current streak.
- Persist data locally (no auth, no cloud DB).

## Out of scope (for now)
- Multi-user support
- Sync across devices
- Notifications
- Advanced analytics
